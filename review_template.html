使用说明与算法信息

键盘复核：先点击“下一个待复核”定位橙圈；按数字 1 确认当前点，或按数字 2 删除当前点，画面保持当前位置。按 Enter 再跳到下一个待复核点；直接按 Enter 可暂时跳过。切换下一项前，可用 1 / 2 改变判断；误操作可用 Ctrl / Command + Z 撤销。

建议先检查橙点，再沿图像逐区核对。自动计数仍可能出现漏检、重叠颗粒拆分错误和颜色边界误判。

“删除 / 恢复”点击圆圈切换是否计数；“增加漏检”在颗粒中心单击；“确认待复核”将橙点变为绿色，计数不变。删除误检后，可点击“一键确认本图剩余待复核”将本图未删除的橙点全部变绿；已删除点保持删除，其他图片不受影响，支持一次撤销。各模式都支持按住空格或三指拖动。滚轮以鼠标位置为中心缩放，Ctrl / Command + Z 撤销本次打开页面后的操作。

只有原图范围内可新增标记；手动点以原图像素坐标保存。切换图片不会清除修改。数据版本变化后使用新的本地保存空间，避免混入旧结果；浏览器可能限制 file:// 页面的本地存储，此时请及时导出。
